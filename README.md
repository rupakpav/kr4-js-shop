# mouseshop · контрольная работа №4

Учебный магазин компьютерных мышей по теме «JavaScript: интерактивность, DOM, события, формы и валидация». Основа — адаптивная версия из КР №3. Проект использует HTML, CSS и обычный JavaScript.

Автор: Рупаков Павел Анатольевич, ЭФБО-03-25.

Репозиторий: [kr4-js-shop](https://github.com/rupakpav/kr4-js-shop).

## Запуск

Откройте папку проекта в VS Code и запустите `index.html` через Live Server. В браузере откроется адрес вроде http://127.0.0.1:5500/index.html. Переходите по меню сайта в этой вкладке. Если HTML открыт двойным щелчком, переходы по ссылкам магазина передают корзину, тему, промокод и избранное между файлами.

Цены, оценки и наличие заданы для демонстрации. Заявка проверяется в браузере. Имя, телефон, e-mail и комментарий не сохраняются и не отправляются.

## JavaScript

| Файл | Назначение |
| --- | --- |
| `js/data.js` | Массив `products` из восьми объектов и подписи категорий |
| `js/storage.js` | Сохранение и чтение JSON в `localStorage` с запасным значением при ошибке |
| `js/main.js` | Форматирование цен, скидки, функции обработки массива, общие DOM-элементы и тема |
| `js/catalog.js` | Создание карточек, обработка фильтров, пагинация и избранное |
| `js/cart.js` | Добавление, изменение количества, удаление, сумма через `reduce`, промокод и счётчик в меню |
| `js/product.js` | Разделы характеристик и ссылки к отдельным моделям |
| `js/modal.js` | Быстрый просмотр товара, диалог заявки, возврат фокуса |

Скрипты подключены через `defer` в порядке зависимостей. `data.js` загружается раньше файлов, которые используют товары.

### Данные и расчёты

Каждый объект имеет одинаковые поля `id`, `title`, `brand`, `category`, `price`, `discountPercent`, `rating`, `isAvailable`, `featured`, `connection` и `description`. Строковый `id` уникален. По нему работают ссылки на характеристики, выбор модели из URL и восстановление корзины. Категории `wired` и `wireless` совпадают со значениями фильтра. Цена и скидка хранятся числами.

Поиск приводит запрос и название к нижнему регистру. `trim()` убирает внешние пробелы. Затем `filter()` отбирает категорию, наличие и избранное. Сортировка по итоговой цене или названию применяется к копии. `slice()` берёт шесть элементов текущей страницы. При изменении условий каталог снова показывает первую страницу.

Функции `calculateDiscount` и `calculateFinalPrice` используются для скидки отдельного товара и для промокода. `calculateCartTotals` суммирует итоговые цены товаров, умноженные на количества. Промокод применяется к полученной сумме. `calculateTotalPrice` и `calculateAveragePrice` показывают учебные расчёты по исходным ценам в блоке проверки.

### DOM и форма

Карточка создаётся через `createElement()`. Текстовые поля заполняются с помощью `textContent`, а элементы добавляются через `append()`. Строка с угловыми скобками при таком выводе остаётся текстом. Для данных формы, параметров и объектов товара не используется `innerHTML`.

После обновления каталога общий обработчик на контейнере продолжает принимать клики. `closest()` находит кнопку, а значение из `data-*` определяет товар. Все обработчики подключены через `addEventListener()`.

`preventDefault()` оставляет форму на текущей странице. Скрипт проверяет значения, связывает ошибки с полями через `aria-describedby` и направляет фокус к первой ошибке. Проверка телефона требует 11 цифр с началом 7 или 8. Форматирование отдельно преобразует полный номер в `+7 (900) 123-45-67`. Прошедшая проверку форма очищается, а результат появляется на странице.

### Хранение состояния

Корзина хранит пары `productId` и `quantity`. Цена и наличие берутся из текущего массива. При загрузке отброшены неизвестные модели, недоступные товары и позиции с неверным количеством. Избранное хранит список идентификаторов. Тема и промокод сохраняются отдельными значениями. Ключи начинаются с `mouseshop.kr4.`.

## Самостоятельные доработки по занятию №18

| Доработка | Как проверить |
| --- | --- |
| Корзина и расчёт суммы | Добавьте G305 и G102. Увеличьте количество G305 до двух. Сумма товаров составит 8 920 ₽. Удаление позиции пересчитывает итог и счётчик. |
| Скидка и промокод | Введите `MOUSE10`. Скидка составит 892 ₽, итог — 8 028 ₽. Проверьте неверный код и кнопку «Убрать код». |
| Избранное | Нажмите «Избранное» на карточке и включите «Только избранное». Повторное нажатие снимет отметку. |
| Сохранение | Обновите страницу и перейдите на другую страницу магазина. Проверьте корзину, избранное, применённый промокод и тему. |
| Пагинация и счётчики | В каталоге восемь моделей и две страницы по шесть и две карточки. Поиск `Logitech` оставляет три модели. Число в меню «Корзина» показывает суммарное количество штук. |
| Пустые состояния | Введите запрос без совпадений, включите пустое избранное или удалите последний товар. В каждом случае появится объяснение и действие. |
| Тёмная тема | Нажмите «Тёмная тема» и перейдите по меню. Выбор сохраняется после перезагрузки. В тёмной теме кнопка называется «Светлая тема». |
| Карточки и быстрый просмотр | Сравните метки наличия, рейтинг и скидку. Откройте «Быстрый просмотр» клавишей Enter, закройте Escape и проверьте, куда вернулся фокус. |
| Расширенная проверка | Введите пробелы в поле имени, неверный e-mail, короткий телефон или прошедшую дату. Исправьте значения и проверьте, как убираются ошибки. |
| Имитация отправки | В корзине нажмите «Оформить заявку», заполните форму учебными данными и отправьте. На экране останется подтверждение с количеством и суммой. Поля и оформленная корзина очистятся. |

На телефоне поиск остаётся видимым, а дополнительные фильтры открываются через «Фильтры и сортировка». Таблицы характеристик переносят длинные значения. В светлой теме использованы спокойный фон, белые карточки и зелёные акценты.
